# BNB Guardian V0.0.1 操作与交付边界

## 公开服务部署确认前

先确定域名/服务器与预算。准备好 DNS、HTTPS 反向代理、常驻服务与外部健康监测后，用户确认再部署。当前未选择服务器或域名，不能生成真实注册地址。

Docker 示例（仅供批准后部署，不是已执行）：

```sh
docker build -t bnb-guardian:0.0.1 .
docker run --restart unless-stopped --name bnb-guardian \
  -p 127.0.0.1:8797:8797 --env-file /安全路径/guardian.env \
  bnb-guardian:0.0.1
```

反向代理必须使用域名 Host 转发，TLS 由服务器处理。设置 `PUBLIC_BASE_URL=https://真实域名`，不使用 example.org 注册。

## 未签名交易输入

注册：

```json
{"wallet":"0x9F81A9588c310b90A0636E8D2fb31523a57fbaDC","baseUrl":"https://待确认的真实域名"}
```

上架（ID 必须从注册回执解析，价格和服务期必须由用户确认）：

```json
{"wallet":"0x9F81A9588c310b90A0636E8D2fb31523a57fbaDC","agentWallet":"0x9F81A9588c310b90A0636E8D2fb31523a57fbaDC","agentId":"实际ID","baseUrl":"https://真实域名","priceUsd8PerPeriod":"1000000","periodSeconds":3600}
```

价格示例 `1000000 / 1e8 = US$0.01/小时`，仅是输入格式，不代表已批准收费方案。Agent Wallet 在本版暂用用户钱包，须真正由 Agent 准备的功能操作通过该钱包执行才有相应证据；未来若改为受限智能账户，必须保留 ERC-8004 所有者为报名钱包，并扩展事件核验支持。

偿还：

```json
{"borrower":"0x借贷仓位的钱包","payer":"0x用户确认的付款钱包","market":"0xb7526572FFE56AB9D7489838Bf2E18e3323b441A","capRaw":"1000000000000000000"}
```

金额为 underlying token 原始单位，必须核对 token decimals；不得把示例数额当成 1 美元或自动授权。vBNB 使用原生 tBNB，准备步骤预留的余额判断不能保证实际 Gas 足够，签名前钱包需再次检查。

本轮没有对这些草稿执行签名。请勿自行复制不明 calldata 到主网。

## 资格证据格式

在 config/campaign.json 使用真实记录，不把样例当证据：

```json
{"actions":[{"txHash":"0x实际偿还哈希","borrower":"0x实际借款人"}],"outgoingHires":[{"marketplace":"HelloFugu","chainId":97,"txHash":"0x实际雇佣哈希","subId":"实际订阅ID"}],"externalHires":[{"marketplace":"HelloFugu","chainId":97,"txHash":"0x外部客户雇佣哈希","subId":"实际订阅ID"}]}
```

Actions 不包含 approve/register/list/claim。脚本按区块时间 UTC 日期计算。不要为了次数拆分无必要操作、人为压低 HF、重复借还循环或控制/资助外部客户。

资格报告保留 REVIEW_REQUIRED，不提供“官方资格已通过”承诺。报名、资金独立性、Phase 2 上架时点和原创性需要官方证据与人工审核。
