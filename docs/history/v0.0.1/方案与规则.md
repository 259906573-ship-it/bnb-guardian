# BNB Guardian V0.0.1 技术方案与规则核验

核验日期：2026-10-12。以官方最终审核为准，不承诺获奖。

## 官方要求

活动截止 2026-11-05 12:00 UTC，即北京时间 20:00。所有计分动作应处于活动窗口内且发生于报名之后。前 100 个完成双方要求且经审核的钱包获实物周边；10,000 美元为周边零售总价值，并非现金奖金。

- 使用一个报名钱包；一人一钱包，须符合成年、地区、非主办方/市场团队等资格限制。
- Hire：报名钱包真实雇佣 3 个不同 Agent，覆盖至少 2 个官方入选市场；授权 Token 不等于雇佣。主网与测试网均可计分。
- Build：ERC-8004 注册于 56 或 97，所有者是报名钱包；上架官方市场，Agent Card 可解析，服务可随机调用。
- 获得 3 个独立、非自己控制/资助的钱包的已完成雇佣。
- 至少 5 次实际链上功能操作，跨至少 3 个不同日期；health-factor 类必须对借贷仓位监控并采取行动。
- 仓库公开并记录 Agent ID、链和证据。注册和授权交易不作为偿债操作计数。
- 既有 Agent 的装饰性克隆、多 ID、循环交易、共同资金来源、任务式雇佣后撤销等可能失格。

指定市场：TermiX、Agent Souk、Dolphin、HelloFugu、KATTEGAT、Marque Trade、Pokter、Agent Atlas、Mandate。

报名入口为官方页面的 Google Form。页面要求先报名，同时要求 GitHub 公开 Agent ID；表单实际是否允许后补需要人工核对。不得自行认为已报名或擅自回填报名时间。

## 实现结构

Node 22 + ethers：固定链 97，读取 Venus Comptroller、账户快照及预言机，使用 bigint 风险计算。风险指标为 Venus 抵押因子覆盖率，并非 Aave 清算阈值 HF。无债务时 HF=null，安全时不发交易；默认触发 1.25、目标 1.50，仅生成白名单市场的偿债交易。

所有交易当前由用户钱包确认；准备步骤校验链、金额、余额、额度、目标 Comptroller、仿真与有效期。不借款，不撤出抵押品，不创建任意转账。VAI 债务暂不支持，发现即拒绝处理。ERC20 额度不足时生成精确授权，需单独确认；授权不计入功能操作。

服务暴露 `/healthz`、`/agent-registration.json`、`/.well-known/agent-card.json`（ERC-8004 注册格式，非 A2A 协议卡）、`/mcp`、`/v1/position`、`/v1/watch`。60 秒监控轮询，链读取失败则返回 503。MCP 当前提供查询工具。交易准备由 CLI 完成，尚未接入市场订阅自动执行。

AI 通过可选 OpenAI Responses 风险解释接口工作；规则决定金额，AI 不能改变交易。不配置 API Key/模型则是 rules-only，不能声称完整 AI 已验证。需要补模型配置与真实调用后才能交付正式 AI Agent。

## 成本与最短路径

预算估算：服务器 US$5–15/月，域名 US$10–20/年（已有可省），AI US$0–10/月。测试币使用水龙头，正式报价以选定服务商/市场实时报价为准。Gas 以模拟估算乘链上费率，不固定许诺费用。TermiX 质押/费用和 Mandate 稳定币费用均未执行。

本地实现约 1–2 天，上线接入另预留 1–2 天；真实用户获取无法保证。最早计分只能在报名、服务上线、合法风险仓位与用户授权之后开始。至少三个 UTC 日期，不能在一个日期内生成五笔交易冒充。

1. 先完成官方报名核对；公开项目代码。
2. 明确服务器、域名、AI 配置，用户确认服务部署。
3. 生成真实 HTTPS 注册卡，用户确认 ERC-8004 注册与 HelloFugu 上架。
4. 处理真实测试网借贷需求，用户确认必要的借贷设立/偿债，不为计数人为恶化仓位。
5. 完成市场交付联动；获取真实外部用户，不能控制或资助客户钱包。
6. 核实第二市场入口和费用后，由报名钱包雇佣不同 Agent。
7. 保存交易回执与 UTC 时间，独立验证，再交官方审核。
