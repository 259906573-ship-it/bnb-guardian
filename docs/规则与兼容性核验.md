# BNB Guardian V0.0.3 规则与兼容性核验

核验日期：2026-10-12。资格以 BNB Chain 最终审核为准；本报告不承诺获得前 100 名名额。

## 规则与证据边界

活动结束于 2026-11-05 12:00 UTC（北京时间 20:00）。先完成官方报名，全部计分动作在活动窗口内。奖品为实物周边，网页的 $10,000 是总零售价值。

报名钱包需雇佣 3 个不同 Agent，覆盖至少 2 个指定市场；只有授权而无实际链上雇佣事件不算。Build 要求：Chain 56/97 上 ERC-8004 身份属于报名钱包；指定市场上架；公开卡片及持续可调用服务；3 个非本人控制/资助钱包完成雇佣；至少 5 次与类别一致的真实链上功能动作，分布至少 3 日；公开源码。共同资金来源、循环、为任务而雇佣后撤销、装饰性克隆、多身份重复参与可能失格。

官方文本说“3 separate days”，未明确定义日界线。工程审计暂按 UTC 日期且相邻执行窗口隔至少 24 小时，最终解释仍需主办方确认。不得把注册、上架、授权、雇佣支付或查询请求算作偿债功能操作。用户独立签名的 Agent 草稿是否足以证明 Agent-origin，须公开计划/回执绑定并交主办方审核。

## HelloFugu 上架与交付

`register(string)` 注册身份；回执 `Registered` 才产生真实 agent_id。eth_call 的预测 ID 会变化，不记入审计。`list(id, operatingWallet, 3, priceUsd8, periodSeconds, metadataURI)` 需要身份所有者签名。身份元数据 HTTPS URI 与市场上架元数据是两个用途；市场使用内联 data URI 以兼容其 listing reader，身份保持公开 HTTPS 服务。不是复制 HelloFugu 的 MockLendingPool Agent。

雇佣使用 `subscribe(listingId, periods, nativeToken, maxAmount, deadline)`：实时 oracle 报价、明确支付上限、短有效期；当前只准备 native tBNB 草稿。`Subscribed` 为真实雇佣；`endsAt` 到期、未取消、`claimed == deposited` 并有实际服务交付才进入外部完成雇佣审计。收款 `claim` 会产生链上资金转移，必须另外确认。

`/v1/marketplace/challenge` 产生域名、Chain 97、订阅、账户、有效期绑定的只读签名文本。客户端自行签名后 `/v1/marketplace/invoke` 核对订阅有效、订阅者、Agent ID、所有者和 category，再产生公开链上风险报告及 D1 交付哈希。签名只许可读取报告，不许可资金操作；重放不会增加交付计数。没有真实身份及订阅前，成功雇佣端到端验证仍是阻塞项。
